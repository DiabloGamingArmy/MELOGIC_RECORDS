## A. Spectral Tune audit (1–14)

1. **Issues found:** valid shifted arrivals above FX HIGH were overwritten; above-Nyquist shifts retained original untuned peaks; two-tap interpolation attenuated fractional translations; Smooth averaged bin displacement; nearest-target selection had no hysteresis. The fresh architecture/ownership audit is in [AUDIT.md](AUDIT.md).
2. **HF root cause:** the final destination loop confused source eligibility with output bandwidth. It replaced valid mapped arrivals outside FX bounds with the original spectrum. FX HIGH must govern which input is processed, not erase output above that frequency.
3. **Positive Shift root cause:** the destination overwrite, fractional interpolation loss, and retention of untuned out-of-band source peaks. Truly beyond-Nyquist information cannot survive an upward shift without changing its pitch or aliasing. Dense-region collisions and imperfect source tracking remain separate limitations.
4. **Smooth root cause:** averaging `target − source` in linear bins leaves residual pitch motion when the source moves around a stationary lattice note. The missing boundary hysteresis also allowed nearest-note chatter.
5. **DSP changes:** source-domain boundary blending; preserve original exterior contributions plus valid arrivals; discard shifted out-of-band lobes; four-point centred Lagrange translation; smooth absolute musical targets in MIDI/log-frequency; 0.12 st bounded target hysteresis; remove redundant target log/exp conversions. FFT sizes, windowing, phase propagation, collision budget, envelope model, graph latency and dry/wet architecture are retained.
6. **Justification:** source eligibility is independent of destination frequency. Four-point Lagrange retains exact integer translations and reduces fractional interpolation attenuation with four bounded taps. Absolute log targets preserve a settled musical note while still smoothing note changes. Hysteresis is allowed only while the old note remains in the current mask/range and at most 0.12 st worse than the nearest candidate. No shelf, exciter, limiter, normalization, generated harmonics or aliased folding was added. Background: [Smith, interpolation response](https://www.dsprelated.com/freebooks/pasp/Linear_Interpolation_Frequency_Response.html), [Lagrange interpolation](https://mail.dsprelated.com/freebooks/pasp/Lagrange_Interpolation.html), [Laroche & Dolson, phase-vocoder modification](https://labrosa.ee.columbia.edu/~dpwe/papers/LaroD99-pvoc.pdf).
