17. **Latency audit:** FFT remains N=2048/4096/8192 at 44.1–48/96/192kHz; H=N/4; periodic Hann analysis/synthesis with squared-window normalization. A frame beginning at sample s observes samples s…s+N−1. Its modified inverse FFT can depend on that final input, so it cannot finish before s+N−1. The synthesis coefficient at i=0 is exactly zero; i=1 is nonzero.
18. **Minimal bound:** for the existing full-frame processing/window support, emitting i=1 at frame completion requires s+1+D=s+N−1, hence **D=N−2**. Lower delays such as N−H or N/2 would require future input, dropping nonzero synthesis support, or changing the architecture/quality. The old N schedule was conservative by two samples: frame processing followed the output read and placed its zero-leading window one slot later than necessary. This bound applies to the present frame algorithm and window, not every possible STFT design.
19. **Redundancy removed:** process the completed frame before reading the current output slot, and start OLA placement one slot earlier. Report **2046 / 4094 / 8190** samples. Phase/frame-start accounting, FFT, overlap, window and callback spectra are unchanged. No entire FFT window was redundant. No low-quality or low-latency mode was added.
