# Origami L01.1 — sign-in repair and mandatory authorization gate

1. **Baseline:** `783d2baeef3b1b296a02904dc891826905bd4c8d`, branch
   `mct-origami-nodes-visual-feedback-p03`, clean tree. Release wrappers built;
   baseline state/account/plugin/EQ CTest passed **4/4** before edits.
2. **Exact current failure:** native probe fails at **begin_login / HTTP 404**;
   the production begin Function and `/auth/desktop` both are undeployed. The
   failure occurs before browser launch, approval, token exchange or Keychain.
   L01's generic Protocol error obscured this deployment failure.
3. **Additional proven defects/fixes:** JUCE's `true` POST parameter flag moved
   Firebase's API identifier out of its URL and prepended it to JSON. Production
   now uses the corrected request helper. Loopback request-byte regression passes.
   Live invalid-fixture probe: legacy **403 / API identifier rejected**, repaired
   **400 / INVALID_CUSTOM_TOKEN**. Exact deadline bounds also rejected valid
   responses after transit; bounded tolerance now clamps lifetime, with tests.
   Safe stage/status diagnostics and actionable production messages replace the
   generic-only error. Deployment is still required to resolve the live 404.
4. **Repaired authentication flow:** canonical browser/Firebase login → explicit
   code confirmation → one-time S256 proof → server custom token → repaired REST
   exchange/account lookup → Keychain → shared identity. Grant consumption now
   also rejects account revocation after approval using authenticated auth_time.
   Pending UI is immediate/cancellable; completed URLs are cleared, not replayed.
5. **Authorization architecture:** explicit Restoring, Unauthorized, Authenticating,
   RedeemingKey, Authorized and Error, separate from account identity. Backend
   validates active Origami/beta entitlement. At most 15-minute RAM validation
   lease, startup online validation and retry/recheck. No unsigned persisted grant.
6. **Activation surface:** full-editor Origami branding, dark restrained surfaces,
   Sign In, masked key input/Activate, safe status, cancel/logout, recheck and
   canonical Open Account link. Sign-in alone does not dismiss it.
7. **Editor blocking:** one disabled parent owns all normal editor controls; full
   overlay captures hit testing. Root history/keyboard/mouse/drop handlers also
   check current authorization. Transient menus close on gating. No hundred-control
   disable list. Activation keyboard entry/paste remain available. UI refresh 15 Hz.
8. **Audio gate:** every shipping format uses the same processor, which reads a
   shared lock-free atomic bool. Unauthorized buffers, MIDI and meters are
   explicitly cleared before rendering. Gate is closed during startup restoration.
9. **Realtime evidence:** existing audio-owner reset methods clear runtime/FX;
   no auth mutex, network, filesystem, Keychain, JSON, browser, UI dispatch or
   licensing allocation occurs in callback. New loss/startup callback heap checks
   pass. Existing B01 cases/guards remain intact; authorized tests use explicit
   constructor injection rather than fake account ownership.
10. **MIDI/voice behavior:** loss resets engine/FX/ARP, expression and pending UI
    notes/controllers. Unauthorized MIDI is ignored, not accumulated. Reopening
    accepts new MIDI from a sane state. Delay tails are checked through 400 blocks
    after reopening. Immediate silence at the next callback can cause a boundary
    click; this pass does not let residual output continue after access closes.
11. **Key redemption:** account-bound, HTTPS, SHA-256 digest lookup, opaque
    case-sensitive key, outer whitespace trimming only. Trusted Firestore
    transaction checks product, beta edition, status, expiry, capacity and receipt;
    grants canonical entitlement and consumes capacity atomically. Same-UID retries
    are idempotent; revoked ownership cannot be resurrected by a receipt.
12. **Backend changes:** two new revoked-token-checked callables,
    `getOrigamiAuthorization` / `redeemOrigamiLicense`; server-only redemption
    receipts beneath hashed key documents; rate limiting. No issued key, production
    entitlement or product document generated by the pass.
13. **Rules:** L01's owner-read/backend-write entitlement rules and server-only
    license-key/activation boundaries remain sufficient and unchanged. Default
    deny also protects nested key receipts. No rules are weakened.
14. **Unlicensed account:** remains signed in, gated and silent, with clear
    not-licensed status, legitimate key entry, recheck, Open Account and logout.
    Covered by coordinator and actual editor tests.
15. **Sharing:** one service/atomic per loaded module; shared Keychain/generation
    across processes. Redemption changes generation so other formats promptly
    revalidate. Three simulated format-facing coordinators and three actual
    processor/editor instances validate authorization/loss without patch mutation.
    These are automated fixtures, not a claim of interactive Logic testing.
16. **Logout:** immediately closes local atomic access, tombstones/deletes shared
    authentication and propagates. Permanent Firestore entitlement stays intact.
    There is no separate signed offline activation to retain in L01.1.
17. **State separation:** account, authorization, tokens and raw keys are absent
    from DAW/preset/history/Nodes/Matrix serialization. Complex oscillator/bus/Nodes
    delay/modulation fixtures restore/save intact while gated. Login/logout and
    preset/project/Undo/Redo isolation tests remain enabled.
18. **Account/auth tests:** **61 checks**, including the real isolated Keychain,
    transport request-byte check, callback mismatch/timeout, shared storage,
    revocation, cancellation/shutdown, deadline tolerance and atomic publication.
    Backend/rules emulator tests pass; exact totals in `validation.txt`.
19. **Gate tests:** focused UI/audio run **3,285 checks**, including exhaustive
    editor hit routing, key paste, root shortcuts/drops, silent startup/restored
    project, nonzero authorized output, loss reset, hidden MIDI and delayed tails.
    Additional authenticated-unlicensed editor test passes in the full UI suite.
    A synthetic text-input test was corrected to dispatch JUCE's text-change
    callback before checking button state; no production assertion was removed.
20. **B01/EQ:** complete Release validation includes dedicated torture and EQ
    headroom; exact current counts retained in `validation.txt`. No synthesis
    implementation or existing adversarial case was removed/relaxed.
21. **Release wrappers:** clean Release full build plus a fresh tests-OFF shipping
    tree builds AU/VST3/Standalone. Local ad-hoc test signatures verify after bundle
    resource assembly. No sanitizer dependency or test authorization/installer
    symbol in shipping binaries. These are not notarized distribution signatures.
22. **L02 limits:** signed offline activation/verification, offline policy,
    activation limits, issuance/provisioning workflow and richer revocation policy
    remain. Current validation is online at startup/periodically, always off the
    audio thread. User/host Keychain permissions and shutdown behavior need signed
    real-host validation. No interactive personal login is claimed.
23. **Beta decision:** **BLOCK account-gated Beta distribution until the missing
    backend/Hosting deployment, legitimate entitlement/key provisioning and real
    signed-host end-to-end tests are complete.** Deployment requires explicit
    approval of the live Firebase/website change. Existing ASan classification
    remains **ASAN UNAVAILABLE — TOOLCHAIN/RUNTIME**, unchanged, not reopened.
24. **Delivery:** the final response records the source commit hash/push. Source,
    backend tests, screenshots, security evidence and exact deployment/acceptance
    instructions are included; no credentials, raw issued keys, personal account
    data, generated build trees or Keychain contents are committed.
